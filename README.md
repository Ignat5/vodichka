# Водичка

Котики Крош и Рысик напоминают Лене пить водичку. A small water tracker that runs in the browser: no account, no server, records stay on her computer.

Open the site once, then install it: in Safari use File → Add to Dock, in Chrome use the install icon in the address bar. Reminders and notifications work while the app window is open (it can be minimised). Backups live in Settings → «Данные».

Plain HTML, CSS and JavaScript with no build step: `index.html`, `style.css`, `core.js` (data and rules), `art.js` (cats and bowl), `app.js` (screens and reminders), `sw.js` (offline and notification taps).
